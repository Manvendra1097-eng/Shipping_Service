# Shipping Service

Welcome to the Shipping Service documentation. This is a Python-based service for managing shipments with a modern API built using FastAPI.

## Overview

The Shipping Service provides a RESTful API for tracking and managing shipments. It demonstrates modern Python web development practices including:

- **FastAPI** - High-performance async web framework
- **Decorator Pattern** - Advanced routing and request handling
- **Scalar API UI** - Beautiful API documentation and testing interface

## Features

- 📦 Track shipment status
- 🚀 Fast and async API endpoints
- 📖 Interactive API documentation with Scalar UI
- 🎨 Clean code with design patterns
